# Turn a verified report into the recipient's actual form

## Derive a form contract

Open the current program's template/form when available. Record each required field, its exact label, supported choices and the evidence supplying its value. The program's wording overrides a generic platform profile. Do not convert internal helper JSON into an undocumented submission API payload.

| Form concept | Evidence to use | If unavailable |
|---|---|---|
| Target/asset | Exact affected asset and verified program scope entry | Keep asset selection unresolved |
| Weakness/type | Demonstrated root cause and current supported taxonomy option | Describe cause in prose; flag selection gap |
| Steps/PoC | Controlled actor setup, raw redacted requests and decisive effect | Preserve missing prerequisite; do not invent a request |
| Impact | Actual protected bytes/state/authority transition | Remove unsupported escalation |
| Severity | Program method and substantiated inputs/vector if used | Leave undetermined with rationale |
| Custom required fields | Actual current form plus finding-specific values | List the exact unanswered field |
| Attachments | Reviewed bytes pertinent to this finding/recipient | Do not reuse unrelated private evidence |

## Adapt the writing

For a verified HackerOne route, use the live asset/weakness and program template. For Bugcrowd, reconcile the actual target and applicable current VRT option without equating a priority number with CVSS. For Intigriti or YesWeHack, read the receiving program's severity, language and required metadata. For a direct VDP, follow the owner's contact/encryption and product/version instructions. These are drafting decisions; names alone do not establish access or eligibility.

If the user requests alternate platform drafts without a verified destination, label them alternatives and preserve routing blockers. Do not create several external submissions. Deliver a readable report, exact field handoff and outstanding-field list for one intended recipient; transmitting it remains a separate authorized action.
