# Select a bounded investigation from actual evidence

## Worked selection: a multi-tenant document service

Given API routes, a JavaScript bundle and a complaint about export privacy, start with the private-document invariant. Select object authorization for the referenced document and background-job authority for its delayed consumer. Use JavaScript analysis only to reconstruct the actual export call when its route/body are missing. Add mass-assignment review only if a caller-writable authority field is evidenced; do not load every authentication/cloud/native skill because the application has login and runs on a server.

Track a hypothesis as: policy, actor/resource, controlled input, check-to-consumer trace, decisive observation, disproof/entitled control and next missing artifact. If the direct document endpoint denies but a queued export is accepted, inspect worker consumption before confirming disclosure. If the worker is unavailable, finish source analysis and retain a specific gap. A candidate from a scanner or extracted string starts a hypothesis, not a finding.

## Completion and handoff

For every requested material boundary, record assessed, not assessed with reason, or not applicable with evidence. Separate supported findings from rejected hypotheses and unexecuted checks. Do not calculate a reassuring coverage percentage from how many skills/controls were listed. Reuse current evidence, issue one report per independent cause, and route/format only when reporting is requested. Without a real affected owner, deliver a neutral report and unresolved destination.

The coordinator can work sequentially in any agent. Delegation is a separate execution choice requiring the session's authorization; loading this skill does not create it. Use the local brief as a working note, not a mandatory document for a trivial review.
