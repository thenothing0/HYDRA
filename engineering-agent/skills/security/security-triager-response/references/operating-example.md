# Answer the disputed claim with one decisive comparison

Suppose triage asks whether the exported document was deliberately shared. Use the actual fixture's owner/share policy, A's denied direct read and the export response containing B's synthetic marker. State which account queued the export and which account downloaded its result. Do not answer with a different account's screenshot or a broader impact claim.

A useful draft shape is: “The document was private to tenant B under [policy evidence]. With tenant A's unchanged session, the direct read was denied [E1], while the export path returned B's marker [E2]. The owner control succeeded [E3]. This supports cross-tenant document disclosure through export; I have not demonstrated administrator takeover.” Replace every reference with actual supplied evidence; if the policy is missing, say that and ask for the specific sharing rule.

For a duplicate dispute, compare only known affected function, root cause, actor and repair boundary. An inaccessible private duplicate is unknown, not proof the decision is wrong. For severity feedback, correct unsupported claims and show the actual prerequisite/impact inputs. Draft one answer per report with only its permitted attachments. Save it locally unless sending this particular reply is already authorized.
